# LLM Noti — 个人 AI 额度看板

一个纯前端 + 本地存储的小工具，用来跟踪每天可用的大模型 / AI 平台额度。

打开就能回答两个问题：

1. **我今天还能用什么？** —— 哪些工具有剩余额度
2. **新任务该用谁？** —— 按任务类型（对话 / 文生图 / 文生视频 / API…）筛选，按剩余额度排序

## 功能

- **工具配置**：名称、分类、链接、免费 / 付费，全部枚举用标签点选
- **三种额度模式**，覆盖真实产品的计费方式：
  - **不限量**：订阅套餐（Claude Max）、免费无限（DeepSeek 网页版），只记任务不扣量
  - **单额度池**：每日 N 次（DeepSider）、充值余额（DeepSeek API）
  - **双额度池**：余额（充值/一次性）+ 每日免费（Manus、Allyhub、Lovart），记账时可选扣哪个池
- **重置规则**：每池独立，每日 / 每月（可选几号）/ 不自动，时刻可自定义（适配海外服务的 UTC 重置）；所有工具可手动清零
- **有效期**：任何工具都可配起止日期（订阅期、代金券有效期），过期自动置灰
- **记一笔**：记录消耗量 + 任务描述，同时是扣额度动作和使用日志
- **今日看板**：按分类分组的卡片，剩余额度进度条，用尽的置灰沉底
- **历史**：按天回看用了哪些工具、做了什么任务
- **导入 / 导出**：JSON 备份、换机迁移

## 重置的实现方式

纯前端没有后台定时任务，采用**打开时结转**：每次加载页面，对每个工具计算「最近一次应重置时刻」，若上次重置早于该时刻，则将当前周期用量归零（日志保留作为历史）。哪怕几天没打开，逻辑也正确。

## 技术栈

- Vite + React + TypeScript
- 数据存 `localStorage`（带 schema 版本号，便于后续迁移）
- 无后端、无账号，构建产物为纯静态文件
